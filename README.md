# Youtube_Trending_analysis
## 📊 Dataset Used

This project uses the [YouTube Trending Video Dataset](https://www.kaggle.com/datasets/rsrishav/youtube-trending-video-dataset) from Kaggle.

We specifically used the `US_youtube_trending_data.csv` file from the **Videos** folder.

📁 [Download the dataset on Kaggle](https://www.kaggle.com/datasets/rsrishav/youtube-trending-video-dataset)
